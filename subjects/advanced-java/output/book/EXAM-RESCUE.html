📖 The Design of JDBC (Architecture)

Definition

JDBC (Java Database Connectivity) is a Java API used to connect Java programs to relational databases and run SQL queries.

Main parts

  • JDBC API (java.sql): interfaces/classes like DriverManager, Connection, Statement, PreparedStatement, ResultSet.
  • DriverManager: picks and loads the right driver for the database URL.
  • JDBC Drivers: translate Java database calls into database-specific commands.
  • Database: stores the tables and runs SQL queries.

JDBC Architecture Diagram

Two-Tier:
[Java App] <---> [JDBC Driver] <---> [Database]

Three-Tier:
[Client App] <---> [Web / App Server + JDBC] <---> [Database]

Steps in a JDBC program

  1. Load driver
  2. Connect
  3. Create statement
  4. Execute query
  5. Close

Program: connect to the database

import java.sql.*;
public class ConnectDemo {
    public static void main(String[] args) throws Exception {
        Class.forName("com.mysql.cj.jdbc.Driver");
        Connection con = DriverManager.getConnection(
            "jdbc:mysql://localhost:3306/Shop", "root", "");
        System.out.println("Connected!");
        con.close();
    }
}
Topic trick (parts)All Drivers Drive Daily = JDBC API · DriverManager · Driver · Database
Program steps (every JDBC program)Little Cats Create Extra Chaos = Load driver · Connect · Create statement · Execute · Close
📖 Working with JDBC Statements

Definition

A Statement object is used to send SQL commands to the database through a Connection.

Execute methods

  • executeQuery(sql): SELECT → returns ResultSet.
  • executeUpdate(sql): INSERT/UPDATE/DELETE/DDL → returns int (rows affected).
  • execute(sql): any SQL → returns boolean.
TypeUseCreated by
StatementFixed SQL, no parameterscon.createStatement()
PreparedStatementSQL with ? parameters, precompiled, prevents SQL injectioncon.prepareStatement(sql)
CallableStatementCall stored procedurescon.prepareCall("{call p(?)}")

Program: insert three records into Item (Group C)

import java.sql.*;
public class InsertThreeItems {
    public static void main(String[] args) {
        String url = "jdbc:mysql://localhost:3306/Shop";
        String sql = "INSERT INTO Item (ItemID, Name, UnitPrice, Units, ExpiryDate) VALUES (?, ?, ?, ?, ?)";
        try {
            Class.forName("com.mysql.cj.jdbc.Driver");
            Connection con = DriverManager.getConnection(url, "root", "");
            PreparedStatement ps = con.prepareStatement(sql);

            ps.setInt(1, 1); ps.setString(2, "Pen"); ps.setDouble(3, 15.0);
            ps.setInt(4, 50); ps.setDate(5, Date.valueOf("2027-06-15"));
            ps.executeUpdate();

            ps.setInt(1, 2); ps.setString(2, "Notebook"); ps.setDouble(3, 80.0);
            ps.setInt(4, 20); ps.setDate(5, Date.valueOf("2027-12-01"));
            ps.executeUpdate();

            ps.setInt(1, 3); ps.setString(2, "Eraser"); ps.setDouble(3, 10.0);
            ps.setInt(4, 100); ps.setDate(5, Date.valueOf("2028-01-10"));
            ps.executeUpdate();

            System.out.println("Three records inserted successfully!");
            con.close();
        } catch (Exception e) {
            System.out.println(e);
        }
    }
}

Points trick (3 methods)Queries Update Everything = executeQuery (SELECT) · executeUpdate (INSERT/UPDATE/DELETE) · execute (any)

📖 Frame

Definition

A frame is a main application window (Frame in AWT or JFrame in Swing) with a title bar, border, and close/minimize/maximize buttons.

Ways to create a frame

  • By Inheritance (extends JFrame or Frame): make your class extend JFrame/Frame and set size, layout and visibility in the constructor.
  • By Composition (creating an object): create a JFrame/Frame object inside a class or main() and add components to it.

Program: simple frame

public class MyFrame {
    public static void main(String[] args) {
        JFrame f = new JFrame("My Window");
        f.setSize(300, 200);
        f.setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
        f.setVisible(true);
    }
}
4 steps to show a frame:Cats Sit Closely Very = Create → Size → Close-operation → Visible
2 ways:Inherit (extends) or Create object (new) = "I am a house" or "I own a house"
📖 Mouse Min/Max

Frame creation + program

See Lesson 1 for how a frame is created (inheritance / composition). The program above is the full answer: implements MouseListener, register with addMouseListener(this), use mousePressed for smaller and mouseReleased for greater, leave the other 3 methods empty.

Program: MinMaxMouseApp (exam answer)

public class MinMaxMouseApp extends JFrame implements MouseListener {
    JTextField t1 = new JTextField(10);
    JTextField t2 = new JTextField(10);
    JButton btn = new JButton("Press / Release Mouse");
    JLabel lbl = new JLabel("Result will show here");

    MinMaxMouseApp() {
        setLayout(new FlowLayout());
        add(t1); add(t2); add(btn); add(lbl);
        btn.addMouseListener(this);
        setSize(320, 160);
        setVisible(true);
    }

    public void mousePressed(MouseEvent e) {
        int a = Integer.parseInt(t1.getText());
        int b = Integer.parseInt(t2.getText());
        int smaller = (a < b) ? a : b;
        lbl.setText("Smaller Number: " + smaller);
    }

    public void mouseReleased(MouseEvent e) {
        int a = Integer.parseInt(t1.getText());
        int b = Integer.parseInt(t2.getText());
        int greater = (a > b) ? a : b;
        lbl.setText("Greater Number: " + greater);
    }

    public void mouseClicked(MouseEvent e) {}
    public void mouseEntered(MouseEvent e) {}
    public void mouseExited(MouseEvent e) {}

    public static void main(String[] args) {
        new MinMaxMouseApp();
    }
}

📖 Reading Servlet Parameters

Definition

Servlet parameters are the values sent by an HTML form (or URL). A servlet reads them with methods of ServletRequest.

Key points

  • String getParameter(String name): one value (null if not sent).
  • String[] getParameterValues(String name): many values (checkboxes).
  • Enumeration getParameterNames(): all parameter names.
  • Values are Strings; convert with Integer.parseInt().

Input page (index.html)

<form action="FactorialServlet" method="post">
  Enter Number: <input type="number" name="num" required>
  <input type="submit" value="Calculate Factorial">
</form>

Program: factorial servlet (Group C)

import java.io.*;
import javax.servlet.*;
import javax.servlet.http.*;

public class FactorialServlet extends HttpServlet {
    public void doPost(HttpServletRequest req, HttpServletResponse res)
            throws ServletException, IOException {
        res.setContentType("text/html");
        PrintWriter out = res.getWriter();
        int n = Integer.parseInt(req.getParameter("num"));
        long fact = 1;
        for (int i = 1; i <= n; i++) {
            fact = fact * i;
        }
        out.println("<h3>Factorial of " + n + " is: " + fact + "</h3>");
    }
}

📖 Event Listener

Definition

An Event Listener is a Java interface (in java.awt.event or javax.swing.event) that listens for an event on a GUI component and runs code to respond to it.

Role of Event Listener

  • Connects the Event Source (like a button) to the response code.
  • Provides methods that run automatically when a specific event occurs.
  • Keeps UI design separate from event logic so code stays neat and easy to update.

KeyEvent is a class in java.awt.event that represents a keyboard action when the user presses, types, or releases a key.

Asked in: sample-paper-1 B4 · Topics: u4.t10

📖 Session Tracking (HttpSession)

Definition

HttpSession (javax.servlet.http.HttpSession) is an interface used to remember user data across multiple web requests, because HTTP by itself does not remember past requests.

Key methods

  • setAttribute(String name, Object value) – saves data in the session under a name.
  • getAttribute(String name) – gets saved data by name (null if not there).
  • removeAttribute(String name) – deletes saved data by name.
  • getId() – returns the unique ID of the user’s session.
  • invalidate() – ends the session and clears all saved data (logout).
  • setMaxInactiveInterval(int seconds) – how long the session can stay idle before expiring.
  • isNew() – true if the session was just created.

Session tracking techniques

Cookies · URL rewriting · Hidden form fields · HttpSession

📖 The RMI Programming Model (Architecture)

Definition

RMI (Remote Method Invocation) lets a Java program in one JVM call a method on an object running in another JVM over a network. Its architecture has layers on both client and server.

Key parts

  • Client & Server: client calls remote methods; server holds and runs the remote object.
  • Stub (client side): local stand-in; packs arguments and unpacks return values or errors.
  • Skeleton (server side): receives calls, unpacks arguments, runs the method, sends back the result. (Old; removed after Java 1.2 but still asked.)
  • Remote Reference Layer: handles remote object references and how connections are made.
  • Transport Layer: sends/receives raw data (TCP/IP).
  • RMI Registry: phonebook where the server registers the object name and the client finds it.

Architecture Diagram

+--------+    +------+    +--------------+    +-----------+
| Client | -> | Stub | -> | Remote Ref.  | -> | Transport |
+--------+    +------+    | Layer (RRL)  |    |  Layer    |
                          +--------------+    +-----------+
                                                   | network
+---------------+    +----------+    +--------------+    +-----------+
| Remote Object | <- | Skeleton | <- | Remote Ref.  | <- | Transport |
+---------------+    +----------+    | Layer (RRL)  |    |  Layer    |
                                     +--------------+    +-----------+

Steps to build an RMI app

  1. Define remote interface
  2. Implement it
  3. Start registry
  4. Server binds object
  5. Client looks up and calls

Server pathTransport Serves Objects = Transport → Skeleton → Object
📖 Stubs and Parameter Marshalling

Definition

A stub is a client-side proxy for a remote object. Parameter marshalling is packing method parameters into a byte stream to send them over the network (unmarshalling is unpacking them).

Key points

  • Stub implements the same remote interface as the real object.
  • Stub: starts connection, marshals parameters, sends, waits, unmarshals result.
  • Uses Java serialization for objects.
  • Primitive types are sent by value.
  • Non-remote objects must be Serializable and are sent as copies.
  • Remote objects are sent as stubs (by reference).
  • Since Java 5 stubs are created automatically (no rmic needed).
Topic trickStub = Stand-in, Marshal = Pack
Points trick (passing rules)Primitives Copy, Objects Copy, Remotes Reference = int/double by value · Serializable objects by copy · Remote objects by stub reference

📖 Advantages of Java Beans

Definition

JavaBeans are reusable Java classes with a no-argument constructor, private variables, public getter/setter methods and Serializable support.

Advantages of JavaBeans

  • Easy to reuse in different apps and GUI tools.
  • Hides internal data using getters and setters (encapsulation).
  • Supports saving/sending object state via Serializable (persistence).
  • Supports event listening out of the box.
  • Builder tools can inspect and customize them (introspection, customizers).
  • Platform independent (pure Java).

Definition

An Adapter class gives blank default bodies for all methods of a listener interface that has multiple methods.

📖 Comparing RMI with CORBA

Definition

CORBA (Common Object Request Broker Architecture) is a standard that lets programs written in different languages on different machines talk to each other over a network.

CORBA key points

  • Uses IDL (Interface Definition Language) so any language can understand the interface.
  • Uses an ORB (Object Request Broker) to pass requests and replies between client and object.
  • Works across different languages and operating systems (protocol IIOP).

Life cycle of a servlet 2.5 marks

Asked in: sample-paper-1 B6c · Topics: u4.t02

📖 The Life Cycle of a Servlet

Definition

The servlet life cycle is the set of steps a servlet goes through from loading to removal, managed by the web server/container.

Stages

  • Loading and instantiation: container loads the class and creates one object.
  • init(ServletConfig): runs once when the servlet starts (e.g. opening a DB connection).
  • service(ServletRequest, ServletResponse): runs for every request and calls doGet() or doPost().
  • destroy(): runs once before shutting down to clean up resources.

Diagram

[Load & init()] ---> [service() for each request] ---> [destroy() on shutdown]
Topic trick (order)I Study Daily = init() → service() → destroy()
Points trick (how often)Once Many Once = init once · service many times · destroy once

📖 Row Sets

Definition

RowSet (javax.sql.RowSet) is an interface that extends ResultSet and treats table data from a database as a JavaBean component.

Use of RowSet

  • Makes database reading and updating simpler than plain ResultSet.
  • Sends events automatically when data or cursor position changes.
