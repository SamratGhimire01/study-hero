What Is a Java Bean? [2.5]

🎬 Animation: lessons/u3-what-is-java-bean.html

Definition

A JavaBean is a reusable Java class (software component) that follows simple rules so tools and programs can use it easily.

Rules of a JavaBean

  • Has a public no-argument constructor.
  • Fields (properties) are private.
  • Properties are accessed with public getter/setter methods (getX(), setX(), isX() for boolean).
  • Implements Serializable so its state can be saved.
  • Can fire and listen to events.

Example

public class Student implements java.io.Serializable {
    private String name;
    private int age;
    public Student() { }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }
}

🔒Rule 2: private fields
🔑Rule 3: public getters/setters

Advantages of Java Beans [3]

🎬 Animation: lessons/u3-advantages-javabeans.html

Definition

JavaBeans are reusable Java classes with a no-argument constructor, private variables, public getter/setter methods and Serializable support.

Advantages of JavaBeans

  • Easy to reuse in different apps and GUI tools.
  • Hides internal data using getters and setters (encapsulation).
  • Supports saving/sending object state via Serializable (persistence).
  • Supports event listening out of the box.
  • Builder tools can inspect and customize them (introspection, customizers).
  • Platform independent (pure Java).

Introspection [5]

🎬 Animation: lessons/u3-introspection.html

Definition

Introspection is the process by which a builder tool finds out a bean’s properties, methods and events at run time.

Key points

  • Done by the class java.beans.Introspector.
  • Uses naming patterns (getX/setX, addXListener) via reflection.
  • Or uses an explicit BeanInfo class if the developer provides one.
  • Result is a BeanInfo object with PropertyDescriptor, MethodDescriptor, EventSetDescriptor.

Using BeanInfo Interface [5]

🎬 Animation: lessons/u3-beaninfo.html

Definition

The BeanInfo interface (java.beans) lets a developer explicitly describe a bean’s properties, methods, events, icon and customizer, instead of relying only on naming patterns.

Key points

  • BeanInfo class name = BeanName + "BeanInfo" (e.g. StudentBeanInfo).
  • Usually extends SimpleBeanInfo and overrides only needed methods.
  • Methods: getPropertyDescriptors(), getMethodDescriptors(), getEventSetDescriptors(), getBeanDescriptor(), getIcon().
  • Used to hide properties, give display names, set icons and customizers.

 1  public class Employee {
 2      private int salary;

 6      }

11      }

Persistence [2.5]

🎬 Animation: lessons/u3-persistence.html

Definition

Persistence is the ability of a bean to save its state (property values) and restore it later.

Key points

  • By Serialization: bean implements Serializable; save with ObjectOutputStream, load with ObjectInputStream.
  • By XMLEncoder / XMLDecoder: saves bean properties as XML (long-term persistence).
  • transient fields are not saved.
  • Builder tools use persistence to store a designed GUI.
🫘A bean with data
📦Way 1: Serialization
📄Way 2: XMLEncoder
🙈transient fields are skipped

Customizers [2.5]

🎬 Animation: lessons/u3-customizers.html

Definition

A Customizer is a GUI class that gives a full, user-friendly editor (wizard) for a bean inside a builder tool, instead of the simple property sheet.

Key points

  • Implements java.beans.Customizer and extends Component (usually JPanel).
  • Must have a public no-arg constructor.
  • Methods: setObject(Object bean), addPropertyChangeListener(), removePropertyChangeListener().
  • Registered in BeanInfo: new BeanDescriptor(beanClass, customizerClass).
  • Property editors edit ONE property; a customizer edits the WHOLE bean.

Writing JavaBeans [5]

🎬 Animation: lessons/u3-writing-javabeans.html

Definition

Writing a JavaBean means creating a reusable class that follows bean rules so tools and programs can use it.

Steps

  • Create a public class that implements Serializable.
  • Add a public no-arg constructor.
  • Make fields private.
  • Add getters/setters (and events/bound properties if needed).
  • Compile and package into a JAR with manifest entry Java-Bean: True.

Example

public class Student implements java.io.Serializable {
    private String name;
    private int age;
    public Student() { }
    public String getName() { return name; }
    public void setName(String name) { this.name = name; }
    public int getAge() { return age; }
    public void setAge(int age) { this.age = age; }
}

🚪2. public no-arg constructor
🔒3. private fields
🔑4. getters and setters
