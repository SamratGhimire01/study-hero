The Design of JDBC (Architecture) [5]

🎬 Animation: lessons/u2-jdbc-design.html

Definition

JDBC (Java Database Connectivity) is a Java API used to connect Java programs to relational databases and run SQL queries.

Main parts

  • JDBC API (java.sql): interfaces/classes like DriverManager, Connection, Statement, PreparedStatement, ResultSet.
  • DriverManager: picks and loads the right driver for the database URL.
  • JDBC Drivers: translate Java database calls into database-specific commands.
  • Database: stores the tables and runs SQL queries.

JDBC Architecture Diagram

Two-Tier:
[Java App] <---> [JDBC Driver] <---> [Database]

Three-Tier:
[Client App] <---> [Web / App Server + JDBC] <---> [Database]

Steps in a JDBC program

  1. Load driver
  2. Connect
  3. Create statement
  4. Execute query
  5. Close

JDBC Driver Types and Typical Uses [5]

🎬 Animation: lessons/u2-jdbc-driver-types.html

Definition

A JDBC driver is software that lets a Java program talk to a specific database. There are 4 types.

TypeNameHow it worksPros / Cons
1JDBC-ODBC BridgeJava → ODBC → DBEasy; slow, needs ODBC, removed in Java 8
2Native-API (partly Java)Uses DB client library (C/C++)Faster than 1; needs native install
3Network Protocol (pure Java)Java → middleware server → DBFlexible; needs middle server
4Thin driver (pure Java)Java → DB protocol directlyFastest, portable, most used

Typical uses of JDBC

  • Two-tier: desktop app talks to DB directly.
  • Three-tier: web app (servlet/JSP) uses JDBC on the server.
  • Reports, banking, shop billing, student records.

The Structured Query Language [2.5]

🎬 Animation: lessons/u2-sql.html

Definition

SQL (Structured Query Language) is the standard language to create, read, update and delete data in a relational database. JDBC sends SQL strings to the database.

GroupCommandsUse
DDLCREATE, ALTER, DROPDefine tables
DMLINSERT, UPDATE, DELETEChange data
DQLSELECTRead data
DCLGRANT, REVOKEPermissions
TCLCOMMIT, ROLLBACKTransactions

Example

CREATE TABLE Item (ItemID INT PRIMARY KEY, Name VARCHAR(50),
  UnitPrice DOUBLE, Units INT, ExpiryDate DATE);
INSERT INTO Item VALUES (1, 'Pen', 15.0, 50, '2027-06-15');
SELECT Name, UnitPrice FROM Item WHERE Units > 10;
UPDATE Item SET UnitPrice = 20 WHERE ItemID = 1;
DELETE FROM Item WHERE ItemID = 3;
🏗️DDL: build tables
✏️DML: change rows
🔎DQL: ask
🔑DCL: permissions
Topic trick (5 groups)Dogs Make Quiet Cats Talk = DDL · DML · DQL · DCL · TCL
DML trickI Use Detergent = INSERT · UPDATE · DELETE

JDBC Configuration [2.5]

🎬 Animation: lessons/u2-jdbc-configuration.html

Definition

JDBC configuration means setting up everything a Java program needs to connect to a database.

Steps

  • Install the database and create the database/table.
  • Add the driver JAR (e.g. mysql-connector-j.jar) to the classpath.
  • Write the database URL: jdbc:mysql://localhost:3306/Shop.
  • Load the driver: Class.forName("com.mysql.cj.jdbc.Driver") (automatic since JDBC 4).
  • Connect: DriverManager.getConnection(url, user, password).

Working with JDBC Statements [5 / Group C program]

🎬 Animation: lessons/u2-jdbc-statements.html

Definition

A Statement object is used to send SQL commands to the database through a Connection.

Execute methods

  • executeQuery(sql): SELECT → returns ResultSet.
  • executeUpdate(sql): INSERT/UPDATE/DELETE/DDL → returns int (rows affected).
  • execute(sql): any SQL → returns boolean.
TypeUseCreated by
StatementFixed SQL, no parameterscon.createStatement()
PreparedStatementSQL with ? parameters, precompiled, prevents SQL injectioncon.prepareStatement(sql)
CallableStatementCall stored procedurescon.prepareCall("{call p(?)}")

📋PreparedStatement
📞CallableStatement
🔎executeQuery()

Points trick (3 methods)Queries Update Everything = executeQuery (SELECT) · executeUpdate (INSERT/UPDATE/DELETE) · execute (any)

Code (Program: insert three records into Item (Group C))

 1  import java.sql.*;
 2  public class InsertThreeItems {
 3      public static void main(String[] args) {
 4          String url = "jdbc:mysql://localhost:3306/Shop";
 5          String sql = "INSERT INTO Item (ItemID, Name, UnitPrice, Units, ExpiryDate) VALUES (?, ?, ?, ?, ?)";
 6          try {
 7              Class.forName("com.mysql.cj.jdbc.Driver");
 8              Connection con = DriverManager.getConnection(url, "root", "");
 9              PreparedStatement ps = con.prepareStatement(sql);
10  
11              ps.setInt(1, 1); ps.setString(2, "Pen"); ps.setDouble(3, 15.0);
12              ps.setInt(4, 50); ps.setDate(5, Date.valueOf("2027-06-15"));
13              ps.executeUpdate();
14  
15              ps.setInt(1, 2); ps.setString(2, "Notebook"); ps.setDouble(3, 80.0);
16              ps.setInt(4, 20); ps.setDate(5, Date.valueOf("2027-12-01"));
17              ps.executeUpdate();
18  
19              ps.setInt(1, 3); ps.setString(2, "Eraser"); ps.setDouble(3, 10.0);
20              ps.setInt(4, 100); ps.setDate(5, Date.valueOf("2028-01-10"));
21              ps.executeUpdate();
22  
23              System.out.println("Three records inserted successfully!");
24              con.close();
25          } catch (Exception e) {
26              System.out.println(e);
27          }
28      }
29  }
StepWhat happens
1The SQL has 5 ? marks: holes we fill later.
2L = Load driver.
3C = Connect to database Shop.
4C = Create a PreparedStatement from the SQL.
5Fill holes 1, 2, 3: ItemID=1, Name=Pen, UnitPrice=15.0.
6Fill holes 4 and 5: Units=50, Expiry=2027-06-15.
7E = Execute: row 1 saved in the table.
8Same statement, new values: row 2.
9Row 3.

11C = Close.

Query Execution [5]

🎬 Animation: lessons/u2-query-execution.html

Definition

Query execution means sending a SELECT statement with executeQuery() and reading the returned ResultSet row by row.

Key points

  • ResultSet rs = st.executeQuery(sql);
  • The cursor starts before the first row.
  • rs.next() moves to the next row; returns false at the end.
  • Read values with getInt(), getString(), getDouble(), getDate() by column name or number (starts at 1).
  • Close ResultSet, Statement and Connection after use.

Figure

executeQuery() → ResultSet → while(rs.next()) → rs.getXxx("col") → print
☕Ask: executeQuery("SELECT ")
📑Answer: a ResultSet
👉Cursor starts BEFORE row 1
👉rs.next() moves down
Topic trick (3 steps)All Lions Growl = executeQuery · Loop with rs.next() · getXxx("column")
Points trickBefore First, Next is True = Cursor starts before first row; next() returns true while rows remain

Code (Program: read all items)

 1  Connection con = DriverManager.getConnection("jdbc:mysql://localhost:3306/Shop", "root", "");
 2  Statement st = con.createStatement();
 3  ResultSet rs = st.executeQuery("SELECT ItemID, Name, UnitPrice FROM Item");
 4  while (rs.next()) {
 5      int id = rs.getInt("ItemID");
 6      String name = rs.getString("Name");
 7      double price = rs.getDouble(3);
 8      System.out.println(id + " " + name + " " + price);
 9  }
10  con.close();
StepWhat happens
1Connect.
2Create a Statement.
3Run SELECT → get ResultSet. Cursor is before row 1.
4next() → row 1 exists → true.
5Read the 3 columns (by name or index 3).
6Print row 1.
7Loop again for row 2, 3… then next() gives false and the loop stops.
8Close.
✅ Quick check: Where is the ResultSet cursor at the start? (Before the first row)

Scrollable and Updatable Result Sets [5]

🎬 Animation: lessons/u2-scrollable-updatable-resultset.html

Definition

A scrollable ResultSet lets the cursor move forward, backward or jump to any row. An updatable ResultSet lets us change database rows through the ResultSet.

ResultSet types

  • TYPE_FORWARD_ONLY (default): only next().
  • TYPE_SCROLL_INSENSITIVE: scroll; does not see changes by others.
  • TYPE_SCROLL_SENSITIVE: scroll; sees changes by others.
ConcurrencyMeaning
CONCUR_READ_ONLYCannot change (default)
CONCUR_UPDATABLECan update, insert, delete rows

Methods

  • Move: next(), previous(), first(), last(), absolute(n), relative(n), beforeFirst(), afterLast()
  • Update: updateXxx(col, value) → updateRow(); moveToInsertRow() → insertRow(); deleteRow()

Create

Statement st = con.createStatement(
  ResultSet.TYPE_SCROLL_INSENSITIVE, ResultSet.CONCUR_UPDATABLE);
➡️Default: forward only
🔃TYPE_SCROLL_INSENSITIVE / SENSITIVE
🧭Move anywhere
✏️CONCUR_UPDATABLE
Topic trick (types)Fish In Sea = FORWARD_ONLY · SCROLL_INSENSITIVE · SCROLL_SENSITIVE
Points trick (move methods)Nice People Find Lost Animals Rarely = next · previous · first · last · absolute · relative
Update trickChange Then Save = updateXxx() then updateRow() (insertRow / deleteRow too)

Code (Program: scroll and update)

 1  Statement st = con.createStatement(
 2      ResultSet.TYPE_SCROLL_INSENSITIVE, ResultSet.CONCUR_UPDATABLE);
 3  ResultSet rs = st.executeQuery("SELECT ItemID, Name, UnitPrice FROM Item");
 4  rs.last();
 5  System.out.println("Last item: " + rs.getString("Name"));
 6  rs.absolute(1);
 7  rs.updateDouble("UnitPrice", 20.0);
 8  rs.updateRow();
StepWhat happens
1Ask for a SCROLLABLE and UPDATABLE ResultSet.
2Run the SELECT.
3Jump straight to the last row (not possible with forward-only).
4Print it.
5Jump to row 1.
6Change price in the ResultSet (memory only).
7Save the change to the database.
✅ Quick check: Which method saves an updated row to the database? (updateRow())

Row Sets [2+3]

🎬 Animation: lessons/u2-rowsets.html

Definition

RowSet (javax.sql.RowSet) is an interface that extends ResultSet and treats table data from a database as a JavaBean component.

Use of RowSet

  • Makes database reading and updating simpler than plain ResultSet.
  • Sends events automatically when data or cursor position changes.
PointConnected RowSet (JdbcRowSet)Disconnected RowSet (CachedRowSet, WebRowSet, etc.)
DB connectionKeeps an active connection at all timesFetches data, closes the connection, works offline
Saving changesSaves updates to the DB right awaySaves later when you reconnect and call acceptChanges()
Network / memoryNeeds continuous connection; less local memoryMore memory to hold rows; saves DB connections
SerializableUsually not sent over networkSerializable, can move across tiers
Best forSteady, direct DB accessDistributed, mobile, low-connection apps
🗄️RowSet = ResultSet + JavaBean
🔌Connected: JdbcRowSet
🎒Disconnected: CachedRowSet
🎒Works offline
Topic trick (types)Just Cats Will Find Joy = JdbcRowSet · CachedRowSet · WebRowSet · FilteredRowSet · JoinRowSet
Points trick (difference)Connected = Constantly online, Disconnected = Does work offline
Use trick (2 uses)Simple Signals = Simpler than ResultSet · Sends events (it is a JavaBean)

Code (Program: CachedRowSet (disconnected))

 1  CachedRowSet crs = RowSetProvider.newFactory().createCachedRowSet();
 2  crs.setUrl("jdbc:mysql://localhost:3306/Shop");
 3  crs.setUsername("root");
 4  crs.setPassword("");
 5  crs.setCommand("SELECT * FROM Item");
 6  crs.execute();
 7  while (crs.next()) {
 8      System.out.println(crs.getString("Name"));
 9  }
StepWhat happens
1Make a CachedRowSet using the factory.
2Set connection details like JavaBean properties (setters!).
3Set the SQL.
4Connects, fetches all rows, then DISCONNECTS.
5Loop over rows offline.
6Print names.
