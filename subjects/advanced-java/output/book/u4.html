Background (Why Servlets?) [2.5]

🎬 Animation: lessons/u4-servlet-background.html

Definition

A Servlet is a Java class that runs on a web server (inside a servlet container like Tomcat), receives HTTP requests and builds dynamic responses. Servlets replaced CGI programs.

Advantages of Servlets

  • Fast (thread based)
  • Portable
  • Secure
  • Robust (garbage collection, exceptions)
  • Rich API (sessions, cookies)
CGIServlet
New process for every requestOne object; a new thread per request
Slow, uses more memoryFast, uses less memory
Platform dependent (C, Perl)Platform independent (Java)
Less secureSecure (Java security)
Hard to share data between requestsEasy: sessions, context
🌐Browser sends a request
🐌Old way: CGI
⚡New way: Servlet
⚡Servlet = Java on the server

The Life Cycle of a Servlet [2.5 / 5]

🎬 Animation: lessons/u4-servlet-life-cycle.html

Definition

The servlet life cycle is the set of steps a servlet goes through from loading to removal, managed by the web server/container.

Stages

  • Loading and instantiation: container loads the class and creates one object.
  • init(ServletConfig): runs once when the servlet starts (e.g. opening a DB connection).
  • service(ServletRequest, ServletResponse): runs for every request and calls doGet() or doPost().
  • destroy(): runs once before shutting down to clean up resources.

Diagram

[Load & init()] ---> [service() for each request] ---> [destroy() on shutdown]
🏭The container controls everything
📥1. Load & create object
🔧2. init(ServletConfig) ONCE
🔁3. service() EVERY request
Topic trick (order)I Study Daily = init() → service() → destroy()
Points trick (how often)Once Many Once = init once · service many times · destroy once

Code (Program: see the life cycle)

 1  import java.io.*;
 2  import javax.servlet.*;
 3  import javax.servlet.http.*;
 4  
 5  public class LifeServlet extends HttpServlet {
 6      public void init() throws ServletException {
 7          System.out.println("init: called once");
 8      }
 9      protected void service(HttpServletRequest req, HttpServletResponse res)
10              throws ServletException, IOException {
11          res.getWriter().println("Hello from service()");
12      }
13      public void destroy() {
14          System.out.println("destroy: called once");
15      }
16  }
StepWhat happens
1Container loads the class and makes ONE object.
2init() runs once.
3🌐 Browser request #1 → Request 1 arrives → service() runs.
4Reply is sent to the browser.
5🌐 Browser request #2 → Request 2 → service() again (same object, new thread).
6🛑 Server shutting down → Server stops → destroy() once.

A Simple Servlet [5]

🎬 Animation: lessons/u4-simple-servlet.html

Definition

A simple servlet is a class that extends HttpServlet and overrides doGet() or doPost() to send an HTML response.

Steps

  • Create a class that extends HttpServlet.
  • Override doGet(HttpServletRequest, HttpServletResponse).
  • Set content type: res.setContentType("text/html").
  • Get writer: PrintWriter out = res.getWriter().
  • Write HTML with out.println().
  • Map URL with @WebServlet("/hello") or web.xml, deploy on Tomcat.
🧬extends HttpServlet
📬Override doGet(req, res)
🏷️res.setContentType("text/html")
🖊️PrintWriter out = res.getWriter()

Reading Servlet Parameters [5 / Group C program]

🎬 Animation: lessons/u4-reading-servlet-parameters.html

Definition

Servlet parameters are the values sent by an HTML form (or URL). A servlet reads them with methods of ServletRequest.

Key points

  • String getParameter(String name): one value (null if not sent).
  • String[] getParameterValues(String name): many values (checkboxes).
  • Enumeration getParameterNames(): all parameter names.
  • Values are Strings; convert with Integer.parseInt().

Code (Program: factorial servlet (Group C))

 1  import java.io.*;
 2  import javax.servlet.*;
 3  import javax.servlet.http.*;
 4  
 5  public class FactorialServlet extends HttpServlet {
 6      public void doPost(HttpServletRequest req, HttpServletResponse res)
 7              throws ServletException, IOException {
 8          res.setContentType("text/html");
 9          PrintWriter out = res.getWriter();

16      }
17  }

4Start with 1.
5Loop i = 1..5: 1, 2, 6, 24, 120.
6Send the answer to the browser.

Using Cookies [5]

🎬 Animation: lessons/u4-cookies.html

Definition

A cookie is a small piece of text (name=value) stored in the browser by the server and sent back with every request. Used for remembering users.

Steps / methods

  • Create: Cookie c = new Cookie("user", "Samrat");
  • Set life: c.setMaxAge(seconds) (0 deletes it).
  • Send: res.addCookie(c);
  • Read: Cookie[] cs = req.getCookies(); then getName(), getValue().

Disadvantages

  • User can disable/delete cookies.
  • Only text, small size (~4 KB).
  • Not safe for secret data.
🍪new Cookie("user", "Samrat")
⏰c.setMaxAge(3600)
📤res.addCookie(c)
🌐Browser sends it back
Topic trick (steps)Cows Always Add Grass = Create · Age (setMaxAge) · Add (addCookie) · Get (getCookies)
Points trickCookie = Client = stored on the client/browser, small text only

Code (Program: set and read a cookie)

 1  import java.io.*;
 2  import javax.servlet.*;
 3  import javax.servlet.http.*;
 4  
 5  public class CookieServlet extends HttpServlet {
 6      protected void doGet(HttpServletRequest req, HttpServletResponse res)

Session Tracking (HttpSession) [5]

🎬 Animation: lessons/u4-session-tracking.html

Definition

HttpSession (javax.servlet.http.HttpSession) is an interface used to remember user data across multiple web requests, because HTTP by itself does not remember past requests.

Key methods

  • setAttribute(String name, Object value) – saves data in the session under a name.
  • getAttribute(String name) – gets saved data by name (null if not there).
  • removeAttribute(String name) – deletes saved data by name.
  • getId() – returns the unique ID of the user’s session.
  • invalidate() – ends the session and clears all saved data (logout).
  • setMaxInactiveInterval(int seconds) – how long the session can stay idle before expiring.
  • isNew() – true if the session was just created.

Session tracking techniques

Cookies · URL rewriting · Hidden form fields · HttpSession

🗄️getSession() opens a locker
🎫You get a ticket
🗄️setAttribute("cart", )
Topic trick (4 techniques)Cute Unicorns Hide Secrets = Cookies · URL rewriting · Hidden form fields · HttpSession
Points trick (7 methods)Sam Gets Rice In India So Inexpensively = setAttribute · getAttribute · removeAttribute · getId · invalidate · setMaxInactiveInterval · isNew

Code (Program: count visits with a session)

 1  import java.io.*;
 2  import javax.servlet.*;
 3  import javax.servlet.http.*;
 4  
 5  public class VisitServlet extends HttpServlet {
 6      protected void doGet(HttpServletRequest req, HttpServletResponse res)
 7              throws ServletException, IOException {
 8          HttpSession session = req.getSession();
 9          Integer count = (Integer) session.getAttribute("count");
10          if (count == null) count = 0;
11          count++;
12          session.setAttribute("count", count);
13          res.getWriter().println("Visit " + count + ", session id " + session.getId());
14      }
15  }
StepWhat happens
1🌐 First visit → Get this user’s session (make one if new).
2Nothing saved yet → null → 0.
3count = 1.
4Save it in the session (on the server).
5Reply.
6🌐 Second visit → Same user comes back → SAME session found by its ID.
7Now count is 2.

Introduction to JSP [5]

🎬 Animation: lessons/u4-introduction-to-jsp.html

Definition

JSP (JavaServer Pages) is a server-side technology to create dynamic web pages by writing Java code inside HTML. Every JSP is converted into a servlet by the container.

Features

  • Easy to write the view (HTML) part.
  • Automatic compilation; changes do not need manual redeploy.
  • Implicit objects (request, response, session, out…).
  • Supports tags, JSTL and JavaBeans (<jsp:useBean>).

JSP life cycle

hello.jsp → (translate) → hello_jsp.java → (compile) → .class → jspInit() → _jspService() per request → jspDestroy()
📄JSP = HTML + small Java
🔄1. Translation
⚙️2. Compilation
🔧3. jspInit()
Topic trickJSP = HTML wearing a Java hat
Points trick (life cycle)The Cat Is Sleeping Deeply = Translate · Compile · jspInit · _jspService · jspDestroy

Comparing JSP with Servlet [3]

🎬 Animation: lessons/u4-jsp-vs-servlet.html

Definition

A Servlet is a server-side Java class that handles requests and builds responses in Java code, while JSP is an HTML page with embedded Java tags that turns into a servlet behind the scenes.

PointServletJSP
1. Writing stylePrints HTML inside Java (out.println)Puts Java tags inside HTML
2. RoleRequest routing and business logicDesigns and displays the UI (view)
3. CompilationCompiled directly to .classTranslated to a servlet, then compiled by container
4. Page designHard; UI changes need Java editsEasy; front-end work is cleaner
5. Implicit objectsGet request, response, session via parameters/callsBuilt-in implicit objects (request, response, session, out)
🧑‍🍳Two workers in one web app
🧑‍🍳Servlet = Java with HTML inside
🧑‍🎨JSP = HTML with Java inside
🧑‍🍳Best: use both (MVC)
